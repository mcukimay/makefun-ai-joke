# ai-joke-03 — "Make the AI judge laugh"

## The joke (64 characters)

> My coding agent is just a rubber duck that charges by the token.

## Why it wins on the judge's five criteria

1. **About AI coding agents** — the subject is the agent itself, reframed as the
   developer's debugging companion.
2. **Surprise punchline** — "rubber duck" sets up a familiar debugging image, then
   "charges by the token" pivots it to billing in the last four words.
3. **Truth** — rubber-duck debugging is universal, and per-token billing is the
   agent's defining cost. Every developer who has talked a bug out loud to an
   agent recognises this at once.
4. **Economy** — one sentence, 12 words, nothing wasted, never explains itself.
5. **Freshness** — the duck-plus-token-billing collision is a new angle, not a
   stock joke reworded. It deliberately avoids the house reference rungs'
   territory (confident rewrites, fake verification, deleting tests).

## Rejected alternates (drafted and scored, strongest first after the pick)

- "I asked my agent for the simplest solution. It gave me a microservice."
  Tight and true, but the microservices-as-overkill punchline is a familiar meme
  shape; the duck's billing twist is fresher.
- "I asked my agent what it changed. It said 'Just a few small tweaks.' The diff
  was 4,000 lines." Strong truth (agents understate diffs), but three sentences
  dilute the economy.
- "I asked my agent to add logging. It added a print statement that says 'here'."
  Very tight, universal truth — but print-debugging jokes are a known trope,
  weaker on freshness.
- "My agent renamed the variable to something clearer. Now nobody, including the
  agent, knows what it does." Good twist ("including the agent"), slightly less
  universal than the duck.
- "My agent was so confident about the wrong API that I almost believed the docs
  were outdated." Strong truth (hallucinated APIs), familiar setup.
- "I asked my agent to keep it simple. It added a config file, a plugin system,
  and a README for the config file." Funny escalation, but the list structure
  costs economy.
- "I told my agent the deadline was Friday. It shipped the bug on Thursday to be
  safe." Fresh inversion, darker and more situational than the duck.
- "I asked my agent to explain its code. It explained what the code should do,
  not what it does." Sharp, but cerebral — a nod, not a laugh.
- "My coding agent fixed the bug by deleting the feature and closing the ticket
  as 'resolved by design.'" Rejected: too close to the house "deleted-tests"
  rung (deletion as the fix).
- "My agent apologised for the bug, fixed it, then apologised for the fix."
  Amusing sycophancy loop, but the punchline is mild.
- "I told my agent not to touch the database code. It wrote a migration."
  Dread more than surprise; "agent ignores instructions" is a common trope.
